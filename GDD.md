# GDD — головоломка «Яйцо» (рабочее название)

Игра для платформы Яндекс Игры. HTML5, 2D, мобильные устройства и десктоп.

## Концепция

Головоломка с подвохом: в каждом уровне короткий вопрос или задача, а правильный ответ часто нестандартный — спрятан в интерфейсе, в тексте вопроса или требует неожиданного действия.

Главный герой — **Яйцо**: добродушное, немного трусливое, боится разбиться. Реагирует на ответы игрока эмоциями и короткими репликами. В финале каждой главы трескается сильнее, в финале игры вылупляется.

Тон юмора: добрый, для всех возрастов (6+). Без политики, религии, мата, насилия.

## Механики уровней

Каждый уровень — один из типов:

| Тип | Пример |
| --- | --- |
| `tap` — тапни правильный объект | «Где самое маленькое число?» — ответ: цифра в номере уровня |
| `drag` — перетащи предмет | «Разбуди яйцо» — перетащить солнце из-за облака |
| `choice` — выбери вариант | 4 варианта ответа, правильный — с подвохом |
| `action` — действие с экраном | подождать 5 секунд, нажать на заголовок вопроса, нажать на само яйцо |

Действия, зависящие от поворота телефона, не использовать: на десктопе они невозможны.

## Структура

- 5 глав по 15–20 уровней, всего 60–100 уровней
- Уровни 1–5 — обучение: простые, показывают, что ответ может быть где угодно
- Сложность растёт внутри главы; последний уровень главы — запоминающийся
- Неверный ответ: яйцо пугается, лёгкая тряска экрана, можно пробовать снова без штрафа
- Прогресс: открытые и пройденные уровни, монеты и шапки сохраняются в облаке через SDK

## Экономика

- **Монеты.** За первое прохождение уровня +10 монет, за повторное — 0. Счётчик виден в меню, на экране уровня и в гардеробе
- На что тратятся: подсказка (30 монет) и шапки в гардеробе (50–300 монет)
- Монеты, шапки и счётчики просмотров сохраняются в прогрессе игрока

## Гардероб

Отдельный экран из главного меню. Надетая шапка видна на яйце на всех экранах.

| Шапка | Как получить |
| --- | --- |
| Кепка | 50 монет |
| Бантик | 80 монет |
| Шапка с помпоном | 120 монет |
| Цилиндр | 200 монет |
| Колпак волшебника | 300 монет |
| Корона (редкая) | 3 просмотра рекламы |
| Поварской колпак (редкая) | 3 просмотра рекламы |
| Цветок (редкая) | 3 просмотра рекламы |

Счётчик просмотров у каждой редкой шапки свой и сохраняется. Пока графики нет, шапки нарисованы фигурами в коде (`src/ui/hats.js`, по функции на шапку).

## Секретная глава

Бонусная глава вне основных пяти. В выборе уровней — отдельная кнопка «Секретная глава» с замком. Открывается одним просмотром рекламы за вознаграждение, навсегда. Пока внутри 1 тестовый уровень; файлы уровней — в `src/levels/secret/`.

## Монетизация (реклама через SDK Яндекс Игр)

Вся реклама вызывается только через `src/yandex.js`.

Реклама за вознаграждение (только по нажатию игрока):

- **Подсказка.** Кнопка «Подсказка» открывает выбор: «За 30 монет» или «За рекламу». Если монет не хватает, вариант с монетами серый. После получения подсказка на этом уровне бесплатная
- **Пропуск уровня.** После 3 неверных ответов появляется кнопка «Пропустить (реклама)». Пропущенный уровень считается открытым, но не пройденным: монет за него нет, его можно пройти позже
- **x2 монеты.** На экране победы кнопка «x2 монеты (реклама)»: ещё +10 монет. Только при первом прохождении уровня
- **Редкие шапки** — по 3 просмотра на шапку
- **Секретная глава** — 1 просмотр

Остальная реклама:

- **Межстраничная** — не чаще чем раз в 3 пройденных уровня, только по кнопке «Дальше» между уровнями и не сразу после рекламы за x2
- **Стики-баннер** — показывается всю сессию. Игра не рисует кнопки под баннером: игровое поле учитывает его высоту

Правила:

- На кнопке всегда понятно, что будет реклама и что за неё дадут
- Награда за рекламу — бонус: каждый уровень решаем без подсказки, игра проходится полностью без просмотров
- На время любой рекламы игра и звук на паузе
- Инап-покупок в первой версии нет

## Экраны

1. Загрузка → вызов Game Ready
2. Главное меню: «Играть», выбор уровня, «Гардероб», звук вкл/выкл, счётчик монет
3. Выбор уровня: сетка, закрытые уровни с замком, кнопка «Секретная глава»
4. Уровень: вопрос сверху, игровое поле, яйцо с репликой, счётчик монет, кнопки «Подсказка» и «Меню»; после 3 ошибок — «Пропустить (реклама)»
5. Экран победы: реплика яйца, начисленные монеты, «x2 монеты (реклама)», «Дальше»
6. Гардероб: яйцо и 8 шапок
7. Финал главы и финал игры

## Языки

Русский и английский, автоопределение через SDK. Все тексты — в файлах `src/i18n/ru.json` и `src/i18n/en.json`.

## Технические требования

- Phaser 3 + Vite, JavaScript
- Уровни — JSON-файлы в `src/levels/`, один файл на уровень; секретная глава — в `src/levels/secret/`
- Графика — PNG в `public/assets/`, латинские имена без пробелов
- Адаптив: портрет и альбом, телефон и десктоп, без скролла страницы
- Звук на паузе при уходе со вкладки
- Сборка: `npm run build` → `dist/`, `npm run pack` → zip для Консоли (до 100 МБ, `index.html` в корне)
- Локально SDK заменяется заглушкой: прогресс в localStorage, вместо рекламы — экран «РЕКЛАМА (тест)», вместо баннера — полоса «БАННЕР (тест)»
- Соответствие требованиям Яндекс Игр: https://yandex.ru/dev/games/doc/ru/concepts/requirements
