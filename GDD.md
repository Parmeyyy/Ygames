# GDD — головоломка «Яйцо» (рабочее название)

Игра для платформы Яндекс Игры. HTML5, 2D, мобильные устройства и десктоп.

## Концепция

Головоломка с подвохом: в каждом уровне короткий вопрос или задача, а правильный ответ часто нестандартный — спрятан в интерфейсе, в тексте вопроса или требует неожиданного действия.

Главный герой — **Яйцо**: добродушное, немного трусливое, боится разбиться. Реагирует на ответы игрока эмоциями и короткими репликами. В финале каждой главы трескается сильнее, в финале игры вылупляется.

Тон юмора: добрый, для всех возрастов (6+). Без политики, религии, мата, насилия.

## Механики уровней

Каждый уровень — один из типов:

| Тип | Пример |
| --- | --- |
| `tap` — тапни правильный объект | «Где самое маленькое число?» — ответ: цифра в номере уровня |
| `drag` — перетащи предмет | «Разбуди яйцо» — перетащить солнце из-за облака |
| `choice` — выбери вариант | 4 варианта ответа, правильный — с подвохом |
| `action` — действие с экраном | подождать 5 секунд, нажать на заголовок вопроса, нажать на само яйцо |

Действия, зависящие от поворота телефона, не использовать: на десктопе они невозможны.

## Структура

- 5 глав по 15–20 уровней, всего 60–100 уровней
- Уровни 1–5 — обучение: простые, показывают, что ответ может быть где угодно
- Сложность растёт внутри главы; последний уровень главы — запоминающийся
- Неверный ответ: яйцо пугается, лёгкая тряска экрана, можно пробовать снова без штрафа
- Прогресс: открытые уровни и звёзды сохраняются в облаке через SDK

## Монетизация (реклама через SDK Яндекс Игр)

- **Подсказка** — за просмотр рекламы с вознаграждением. Кнопка подписана: «Подсказка (реклама)»
- **Пропуск уровня** — за просмотр рекламы с вознаграждением, кнопка появляется после 3 ошибок
- **Межстраничная реклама** — не чаще чем раз в 3 пройденных уровня, только на экране между уровнями
- Каждый уровень решаем без подсказки
- На время рекламы игра и звук на паузе
- Инап-покупок в первой версии нет

## Экраны

1. Загрузка → вызов Game Ready
2. Главное меню: «Играть», выбор уровня, звук вкл/выкл
3. Выбор уровня: сетка, закрытые уровни с замком
4. Уровень: вопрос сверху, игровое поле, яйцо с репликой, кнопки «Подсказка» и «Меню»
5. Экран победы: реплика яйца, «Дальше»
6. Финал главы и финал игры

## Языки

Русский и английский, автоопределение через SDK. Все тексты — в файлах `src/i18n/ru.json` и `src/i18n/en.json`.

## Технические требования

- Phaser 3 + Vite, JavaScript
- Уровни — JSON-файлы в `src/levels/`, один файл на уровень
- Графика — PNG в `public/assets/`, латинские имена без пробелов
- Адаптив: портрет и альбом, телефон и десктоп, без скролла страницы
- Звук на паузе при уходе со вкладки
- Сборка: `npm run build` → `dist/`, `npm run pack` → zip для Консоли (до 100 МБ, `index.html` в корне)
- Локально SDK заменяется заглушкой (прогресс в localStorage)
- Соответствие требованиям Яндекс Игр: https://yandex.ru/dev/games/doc/ru/concepts/requirements
